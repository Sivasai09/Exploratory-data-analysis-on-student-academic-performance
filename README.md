# 📊 Exploratory Data Analysis on Student Academic Performance

## 🎯 Project Objective
This project focuses on analyzing student academic performance using Python.  
The goal is to understand how factors like study hours, attendance, and other attributes influence student scores using data visualization and statistical analysis.

---

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## 📁 Dataset
- Dataset: Student Performance Dataset
- Contains information such as:
  - Student ID
  - Study Hours
  - Attendance Percentage
  - Exam Scores
  - Other academic factors

> Note: Dataset is used for exploratory analysis and visualization purposes.

---

## 🔍 Project Workflow

1. Data Loading using Pandas
2. Data Cleaning (handling missing values, duplicates)
3. Exploratory Data Analysis (EDA)
4. Statistical Analysis
5. Data Visualization using Matplotlib & Seaborn
6. Generating insights from patterns

---

## 📊 Features / Analysis Done
- Student score distribution analysis
- Attendance vs performance relationship
- Study hours vs marks correlation
- Identification of top and low performers
- Data visualization using graphs and charts

---

## 📈 Key Insights
- Students with higher study hours generally perform better
- Attendance has a positive impact on exam scores
- A few students show high performance even with moderate attendance
- Performance variation exists across students

---

## 📤 Outputs
- Graphs and charts (bar plots, scatter plots, histograms)
- Insights derived from data
- Summary report of analysis
